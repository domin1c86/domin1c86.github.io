FormatConv: A Local Format Conversion Tool for Windows

When organizing materials, processing videos, compressing images, or converting audio formats daily, we often encounter a problem: tools are too heavy, rely on online services, batch processing is troublesome, or require manual configuration of external tools like FFmpeg and ImageMagick.

FormatConv is a local format conversion software for Windows, primarily used for batch format conversion of videos, audio, and images, as well as the separation and merging of video and audio streams. It uses Flutter for the desktop interface, Go for the local conversion scheduling, and comes bundled with FFmpeg and ImageMagick in the beta version, so users don’t need to install additional command-line tools.

Core Features

FormatConv currently supports local conversion of three types of files and one type of media stream operation:

  • Video: such as MP4, MKV, MOV, AVI, GIF, etc.
  • Audio: such as MP3, FLAC, WAV, AAC, etc.
  • Image: such as PNG, JPEG, JPG, WEBP, BMP, TIFF, GIF, etc.
  • Separate/Merge: Extract video or audio streams from video, and merge a video with an external audio file.

The software supports drag-and-drop file addition, batch selection, image and video preview, task cancellation, conversion history, opening output files with default applications, as well as bilingual support (Chinese/English) and Light/Dark themes.

Local Conversion, Independent of Online Services

The conversion process of FormatConv is completed locally, with no need to upload files to a server. For video and audio, the software calls the bundled FFmpeg; for images, it calls the bundled ImageMagick.

This means:

  • Large files don’t require upload waiting time
  • Materials are processed only locally
  • Can be used without an internet connection
  • Batch conversion is more stable

Note that FFmpeg and ImageMagick are third-party components with their own independent licenses. The source code of FormatConv itself uses the MIT license, but the third-party tools included in the installation package are not covered by FormatConv’s MIT authorization.

Adding Files

After opening the software, the left side is the file workspace. You can add files in two ways:

  1. Click the “Add Files” area to select local files.
  2. Drag and drop files directly from File Explorer to the “Add Files” or “Added Files” area.

Added files will be displayed in the “Added Files” area. The software automatically identifies file types and filters them by “All, Video, Audio, Image.” Image cards show thumbnails, and video cards attempt to capture a frame as a preview; a preview failure will simply fall back to a type icon and does not affect conversion.

File cards support multi-selection. Click a card to select or deselect it; clicking in an empty area of the file section cancels all selections. Selected files can be dragged together to the format cards on the right for conversion; when hovering over a card, you can also use the delete button in the top right corner to remove the file from the workspace.

Files that have already been processed will not disappear immediately; instead, they move to the end of the list with a green status indicator, making it easy to continue processing other formats.

Choosing Output Formats

The right side is the format selection area. Formats are grouped by video, audio, and image, with each format card representing a target format.

The usage is straightforward:

  • Click the right arrow on a format card: Convert the currently selected matching files.
  • Drag a file card to a format card: Convert the dragged file.
  • Drag after multi-selection: Batch convert the selected matching files.

The format name and empty areas of the card will not start a task, reducing accidental operations. The right arrow and settings button have independent hover effects, and only the right arrow is responsible for executing the conversion.

If the file type does not match, the software will automatically refuse the conversion. For example, audio files cannot be dragged onto video formats. GIF and video formats support mutual conversion, which is an exception rule.

Conversion Parameter Settings

Each format card has a settings button on the right. Clicking it allows you to adjust conversion parameters for that format.

Settings vary slightly by type:

  • Audio: Compression rate, audio bitrate, sample rate, number of channels.
  • Image: Compression rate, size ratio, color space, whether to keep metadata.
  • Video: Separately control whether video and audio streams are forced to re-encode, and set encoding, compression rate, resolution, bitrate, frame rate, sample rate, and channels.
  • GIF: Frame rate, frame size, maximum color count, dither algorithm, and loop mode.

Most dropdown options default to “Keep same as source.” During batch conversion, each file is processed based on its own source parameters, rather than applying the first file’s parameters to all.

The image size ratio can be adjusted via a slider from 0% to 200%, or by entering a larger value directly. When metadata is not kept, the output will remove additional information such as shooting time, camera model, and GPS.

Remuxing, Re-encoding, and GPU Acceleration

Video conversion does not always mean re-compression. FormatConv detects video and audio stream encodings before conversion:

  • If the target container supports both source streams and forced re-encoding is not enabled: Streams are copied and remuxed directly.
  • If only one stream is incompatible: Only the incompatible stream is re-encoded.
  • If the user enables forced video or audio re-encoding: The corresponding stream is processed according to the settings on the format card.

Pure remuxing is fast, does not lose quality, and avoids abnormal size increases due to repeated encoding.

When GPU acceleration is enabled, only tasks where video re-encoding actually occurs will attempt to use hardware encoders. The software detects NVIDIA NVENC, Intel QSV, and AMD AMF at runtime; if hardware encoding is unavailable or fails, it automatically falls back to CPU encoding.

Media detection performs multiple attempts and provides alternative detection methods. If encoding information still cannot be confirmed, the software prioritizes safe stream copying or explicit failure, preventing FFmpeg from implicitly choosing an unexpected encoder.

Audio/Video Separation

When the file area contains video, the “Separate/Merge” section is displayed on the right.

“Audio/Video Separation” allows you to choose to output video, audio, or both; at least one option must be kept. The separation process prioritizes stream copying without re-compressing the original streams.

Audio will choose an appropriate container based on its encoding. After output is complete, the software also checks the duration of the source audio and the separated result:

  1. If the duration is normal, the result is kept directly.
  2. If the duration is abnormal, it first re-generates the timeline using the corresponding standard container.
  3. If it’s still abnormal, it re-encapsulates using the MKA container.
  4. If it’s still abnormal, it losslessly reconstructs a continuous audio timeline.

Intermediate files with abnormalities are deleted, ensuring that obviously incorrect results are not left for the user.

Audio/Video Merging

“Audio/Video Merging” accepts exactly one video file and one audio file. After dragging files to the merge card, you can view and delete files in the import list in the settings.

Merge settings include:

  • Auto-merge
  • Remove source video audio track
  • Imported file list

The output container maintains the source video format, and the video stream is prioritized for direct copying. The external audio will align with the video from timestamp 0: if the audio is too long, it’s truncated at the end of the video; if it’s too short, silence is added until the end of the video; if they are the same length, it ends normally.

If “Remove source video audio track” is disabled, the output will keep the original audio track and add the external audio; if enabled, only the video stream and the new external audio are kept.

Conversion Progress Display

Below the format selection area, there is a fixed conversion task floating window. Each time a conversion task starts, a new task card is added here.

New tasks are inserted at the far left of the floating window, and existing tasks move to the right. The task card displays the name of the converted file and continuously estimates processing progress based on the output file size. The progress color fills from the bottom up, and a completion icon appears once finished. Completed task cards can be clicked to open the output file with the system’s default application.

When there are many conversion tasks, the task floating window supports horizontal scrolling for easy viewing of previous tasks.

Tasks running for more than approximately 1.5 seconds will display a cancel button. Clicking it terminates the current conversion and attempts to delete the incomplete output file already generated.

Viewing Results and History

In addition to “Format Selection” on the right, you can switch to “Result Display.”

The result display is divided into two parts:

  • Completed this time
  • History

Each result displays the source filename, converted filename, conversion duration, and operation time, and provides an “Open with Default App” button.

History is saved permanently, making it easy to find previously converted files later. The “Format Selection” and “Result Display” are always switched manually by the user; the page does not jump automatically when a conversion starts or finishes.

Settings

FormatConv provides a complete settings dialog, including General, Preferences, Advanced, and About sections.

General settings include:

  • Default output directory
  • Whether to ask for the save location before each conversion
  • Naming rules after conversion
  • Whether to overwrite source files
  • Whether to enable GPU acceleration

Preferences include:

  • Language selection
  • Light/Dark theme
  • Main interface format display management

Advanced settings default to only showing the developer mode switch. Enabling it requires a second confirmation, after which you can edit theme color JSON, card corner radii, and development/packaging icon paths. Incorrect theme configurations will not be applied directly, and if necessary, all settings can be reset in “About.”

The software supports switching between Chinese and English; the main interface and settings will update immediately after switching.

Output Naming Rules

The software supports customizing the naming rules for converted files.

The current naming format is:

1

name[_$num]

Where name represents the source filename and cannot be modified. The input field must contain and only contain $num once.

When the output file does not have a duplicate name, the software will directly use the original filename; when a duplicate name occurs, it will automatically append a number, for example:

1
2
3

video.mp4
video_1.mp4
video_2.mp4

This avoids accidentally overwriting existing files during batch conversion.

Suitable Use Cases

FormatConv is suitable for the following scenarios:

  • Batch converting videos to MP4, MOV, GIF, and other formats.
  • Converting audio to MP3, WAV, FLAC, and other formats.
  • Compressing images or converting PNG, JPG, WEBP, and other formats.
  • Directly extracting video or audio streams from long videos.
  • Replacing or adding an external audio track to a video.
  • Fast remuxing between compatible encodings to avoid repeated compression.
  • Requiring local processing without uploading files to online tools.
  • Needing a simple and intuitive Windows desktop conversion tool.

Installation and Usage

After downloading the Windows installation package, install it normally. When downloading a new version of the installation package later, you can install it directly over the original directory without uninstalling the old version; it is recommended to exit the running software before upgrading.

Once installed, open FormatConv directly:

  1. Drag in the files to be converted.
  2. After selecting files, click the right arrow on the target format, or drag them to the target format.
  3. Adjust format parameters as needed.
  4. Wait for the conversion to complete.
  5. Open the output file in the results page or task card.

The beta version already bundles FFmpeg and ImageMagick, so regular users do not need to download and install these tools separately.

Technical Implementation

FormatConv consists of three parts:

  • Flutter: Responsible for the Windows desktop interface and interaction.
  • Go + FFI: Responsible for task scheduling, media detection, parameter generation, progress callbacks, and cancellation control.
  • FFmpeg / ImageMagick: Responsible for actual media and image processing.

The release version places FFmpeg, FFprobe, and ImageMagick portable files into the tools/ directory of the installation path. Video conversion also decides between stream copying or re-encoding based on a container compatibility table and automatically executes CPU fallback if hardware encoding fails.
