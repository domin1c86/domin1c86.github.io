FormatConv：一个面向 Windows 的本地格式转换工具

在日常整理素材、处理视频、压缩图片或转换音频格式时，经常会遇到一个问题：工具太重、依赖在线服务、批量处理麻烦，或者需要手动配置 FFmpeg、ImageMagick 等外部工具。

FormatConv 是一个面向 Windows 的本地格式转换软件，主要用于视频、音频、图片的批量格式转换，以及视频流和音频流的分离、合并。它采用 Flutter 构建桌面界面，Go 负责本地转换调度，并随内测版打包 FFmpeg 与 ImageMagick，用户无需额外安装命令行工具。

核心功能

FormatConv 当前支持三类文件的本地转换和一类媒体流操作：

  • 视频：如 MP4、MKV、MOV、AVI、GIF 等格式
  • 音频：如 MP3、FLAC、WAV、AAC 等格式
  • 图片：如 PNG、JPEG、JPG、WEBP、BMP、TIFF、GIF 等格式
  • 分离/合并：从视频中提取视频流或音频流，以及将一个视频和一个外部音频合并

软件支持拖拽添加文件、批量选择、图片和视频预览、任务取消、转换历史记录、默认应用打开输出文件，以及中英文双语言和浅色/深色主题。

本地转换，不依赖在线服务

FormatConv 的转换过程在本机完成，不需要上传文件到服务器。对于视频和音频，软件调用随包附带的 FFmpeg；对于图片，调用随包附带的 ImageMagick。

这意味着：

  • 大文件不需要上传等待
  • 素材仅会本地处理
  • 没有网络时也可以使用
  • 批量转换更稳定

需要注意的是，FFmpeg 与 ImageMagick 是第三方组件，拥有各自独立的许可证。FormatConv 本身源码使用 MIT 协议，但随安装包附带的第三方工具不属于 FormatConv 的 MIT 授权范围。

添加文件

打开软件后，左侧是文件工作区。你可以通过两种方式添加文件：

  1. 点击“添加文件”区域选择本地文件
  2. 直接从资源管理器拖拽文件到“添加文件”或“已添加文件”区域

添加后的文件会展示在“已添加文件”区域。软件会自动识别文件类型，并按“全部、视频、音频、图片”进行分类筛选。图片卡片会显示缩略图，视频卡片会尝试截取画面作为预览；预览失败只会回退为类型图标，不影响转换。

文件卡片支持多选。点击卡片即可选中或取消选中，在文件区空白位置点击可以取消全选。选中的文件可以一起拖拽到右侧格式卡片进行转换；鼠标停留在卡片上时，还可以通过右上角的删除按钮把文件移出工作区。

已经处理过的文件不会立即消失，而是排到列表后方并显示绿色状态标识，方便继续处理其他格式。

选择输出格式

右侧是格式选择区。格式按照视频、音频、图片分组展示，每个格式卡片代表一种目标格式。

使用方式很直接：

  • 点击格式卡右箭头：转换当前选中的匹配文件
  • 拖拽文件卡到格式卡：转换被拖拽的文件
  • 多选后拖拽：批量转换选中的匹配文件

格式名称和卡片空白区域不会启动任务，可以减少误操作。右箭头与设置按钮拥有独立的待选中效果，只有右箭头负责执行转换。

如果文件类型不匹配，软件会自动拒绝转换。例如音频文件不能拖到视频格式上。GIF 与视频格式之间支持互转，这是一个例外规则。

转换参数设置

每个格式卡片右侧都有设置按钮。点击后可以针对该格式调整转换参数。

不同类型支持的设置略有区别：

  • 音频：压缩率、音频码率、采样率、声道数
  • 图片：压缩率、尺寸比例、色彩空间、是否保留元数据
  • 视频：分别控制视频流和音频流是否强制重新编码，并设置编码、压缩率、分辨率、码率、帧率、采样率和声道数
  • GIF：帧率、画面尺寸、最大颜色数、抖动算法和循环模式

大多数下拉选项默认使用“与源保持相同”。批量转换时，每个文件会根据自己的源参数处理，而不是全部套用第一个文件的参数。

图片尺寸比例可以通过滑条在 0% 到 200% 范围内调整，也可以直接输入更大的数值。不保留元数据时，输出会移除拍摄时间、相机型号和 GPS 等附加信息。

重封装、重新编码与 GPU 加速

视频转换并不一定意味着重新压缩。FormatConv 会在转换前探测视频流和音频流编码：

  • 目标容器同时支持两个源流，并且没有开启强制重编码：直接复制流并重封装。
  • 只有某一路不兼容：只重新编码不兼容的流。
  • 用户开启强制视频或音频重编码：按该格式卡片的设置处理对应流。

纯重封装速度快、不会损失质量，也不会因为重复编码导致体积异常增加。

开启 GPU 加速后，只有真正发生视频重编码的任务才会尝试使用硬件编码器。软件会运行时探测 NVIDIA NVENC、Intel QSV 和 AMD AMF；硬件编码不可用或执行失败时，会自动回退到 CPU 编码。

媒体探测会进行多次尝试，并提供备用探测方式。最终仍无法确认编码信息时，软件优先执行安全的流复制或明确失败，不会让 FFmpeg 隐式选择不可预期的编码器。

音视频分离

当文件区包含视频时，右侧会显示“分离/合并”板块。

“音视频分离”可以选择输出视频、音频，或者同时输出两者；两个选项至少会保留一个。分离过程优先使用流复制，不重新压缩原始流。

音频会根据编码选择合适的容器。输出完成后，软件还会检查源音频和分离结果的时长：

  1. 时长正常，直接保留结果。
  2. 时长异常，先使用对应标准容器重新生成时间轴。
  3. 再次异常，改用 MKA 容器重新封装。
  4. 仍然异常时，无损重建连续音频时间轴。

异常中间文件会被删除，不会把明显错误的结果留给用户。

音视频合并

“音视频合并”接受且只接受一个视频文件和一个音频文件。把文件拖到合并卡片后，可以在设置中的导入列表查看和删除文件。

合并设置包括：

  • 自动合并
  • 去除源视频音轨
  • 已导入文件列表

输出容器保持源视频格式，视频流优先直接复制。外部音频会从时间戳 0 与视频对齐：音频过长时在视频结束处截断，音频过短时补静音到视频结尾，两者等长时正常结束。

如果关闭“去除源视频音轨”，输出会保留原音轨并额外加入外部音频；开启后则只保留视频流和新的外部音频。

转换进度展示

格式选择区域下方有一个固定的转换任务浮窗。每当开始一个转换任务，这里就会新增一个任务卡片。

新任务会插入浮窗最左侧，已有任务依次向右移动。任务卡片会显示转换后的文件名称，并根据输出文件大小持续估算处理进度。进度颜色从底部向上填充，转换完成后会显示完成标识。完成后的任务卡片可以点击，用系统默认应用打开输出文件。

当转换任务较多时，任务浮窗支持横向滚动，方便查看之前的任务。

运行超过约 1.5 秒的任务会显示取消按钮。点击后，软件会终止当前转换，并尝试删除已经生成的不完整输出文件。

查看转换结果和历史记录

右侧除了“格式选择”，还可以切换到“结果显示”。

结果显示分为两部分：

  • 本次已完成
  • 历史记录

每条结果会展示源文件名、转换后的文件名、转换耗时、操作时间，并提供“默认应用打开”按钮。

历史记录会持久保存，方便之后查找之前转换过的文件。“格式选择”和“结果显示”始终由用户手动切换，转换开始或完成时不会强制跳转页面。

设置项

FormatConv 提供了完整的设置弹窗，包含常规、偏好、高级和关于几个部分。

常规设置包括：

  • 默认输出目录
  • 每次转换前是否询问保存地址
  • 转换后命名规则
  • 是否覆盖源文件
  • 是否启用 GPU 加速

偏好设置包括：

  • 语言选择
  • 浅色 / 深色主题
  • 主界面格式显示管理

高级设置默认只显示开发者模式开关。开启时需要二次确认，之后可以编辑主题颜色 JSON、卡片圆角和开发/打包图标路径。错误的主题配置不会直接应用，必要时可以在“关于”中重置所有设置。

软件支持中英文双语言切换，切换后主界面和设置界面会立即更新。

输出命名规则

软件支持自定义转换后的文件命名规则。

当前命名方式为：

1

name[_$num]

其中 name 代表源文件名，不可修改。输入框内必须包含且只能包含一次 $num。

当输出文件没有重名时，软件会直接使用原文件名；当发生重名时，会自动追加数字，例如：

1
2
3

video.mp4
video_1.mp4
video_2.mp4

这样可以避免批量转换时意外覆盖已有文件。

适合哪些使用场景

FormatConv 适合以下场景：

  • 批量把视频转换为 MP4、MOV、GIF 等格式
  • 把音频转换为 MP3、WAV、FLAC 等格式
  • 压缩图片或转换 PNG、JPG、WEBP 等格式
  • 从长视频中直接提取视频流或音频流
  • 给视频替换或增加一个外部音轨
  • 在兼容编码之间快速重封装，避免重复压缩
  • 需要本地处理，不希望上传文件到在线工具
  • 需要一个简单直观的 Windows 桌面转换工具

安装和使用

下载 Windows 安装包后，正常安装即可。后续下载新版安装包时，可以直接覆盖安装到原目录，不需要先卸载旧版本；升级前建议先退出正在运行的软件。

安装完成后，直接打开 FormatConv：

  1. 拖入需要转换的文件
  2. 选择文件后点击目标格式右箭头，或拖拽到目标格式
  3. 根据需要调整格式参数
  4. 等待转换完成
  5. 在结果页或任务卡片中打开输出文件

内测版本已经随软件打包 FFmpeg 和 ImageMagick，因此普通用户不需要单独下载安装这些工具。

技术实现

FormatConv 由三部分组成：

  • Flutter：负责 Windows 桌面界面和交互。
  • Go + FFI：负责任务调度、媒体探测、参数生成、进度回调和取消控制。
  • FFmpeg / ImageMagick：负责实际的媒体与图片处理。

发布版会将 FFmpeg、FFprobe 和 ImageMagick portable 文件放入安装目录的 tools/ 中。视频转换还会根据容器兼容表决定流复制或重新编码，并在硬件编码失败时自动执行 CPU 回退。

第三方组件说明

FormatConv 本体源码使用 MIT 协议。

Windows 安装包中随附的第三方组件包括：

  • FFmpeg：用于视频、音频转换和媒体探测；当前 gyan.dev 构建按 GPLv3 处理
  • ImageMagick：用于图片转换，由 ImageMagick Studio LLC 单独授权
  • MiSans：用于界面字体显示，由小米科技有限责任公司单独授权

这些组件由各自项目或权利方单独授权，不属于 FormatConv 的 MIT 授权范围。安装包和项目仓库中会附带对应的第三方声明和许可证信息。

如果在使用中遇到格式兼容、硬件编码或界面问题，可以前往 GitHub Issues 或 Gitee Issues 反馈。提供输入格式、目标格式、是否开启重编码以及错误信息，会更容易定位问题。
